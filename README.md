

# 🧮 Simple Calculator

A **lightweight and interactive calculator** built using **Streamlit**. It performs basic arithmetic operations like **addition, subtraction, multiplication, and division**.

---

## 🎨 Features
✅ **User-friendly interface** 🖥️  
✅ **Supports integers only** 🔢  
✅ **Real-time calculations** ⚡  
✅ **Fast and lightweight** 🚀  
✅ **Built using Streamlit** 🏗️

## 🔧 Installation
Follow these steps to set up the project locally:

```bash
# Clone this repository
git clone https://github.com/yourusername/simple-calculator.git
cd simple-calculator

# Create a virtual environment
python -m venv env

# Activate the environment
# For Windows:
.env\Scripts\activate
# For Mac/Linux:
source env/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run the application
streamlit run main.py
```

---

## 🚀 Usage
1. **Enter two numbers** in the input fields.  
2. **Select an operation** from the dropdown.  
3. Click **"Calculate"** to see the result.
